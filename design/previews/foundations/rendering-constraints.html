Rendering primitives

The desktop stays C + SDL2 with a microui fork. The theming update adds a short list of primitives; every preview here composes only from them. Previews are design artifacts and never ship.

Drawable

  • Filled rectangles with alpha and a per-corner radius (0–6px). re_draw_rrect
  • 1px borders and 1px inner highlight lines. re_draw_frame
  • Soft shadow: one blurred rect behind popovers. re_draw_shadow
  • Two text faces: proportional UI at 11/12/13px, monospace at 13px for cells. re_font_ui, re_font_mono
  • Glyph icons from the bundled icon set, tinted per use. re_icon(id, color)
  • Focus ring: 2px rect outside a control. re_draw_ring
  • Hover transitions ≤ 90ms; frame redraw while a transition is live.
  • Every colour and metric resolved through the theme file at startup; live reload from the theme panel.

Still out of scope

  • Gradients other than the 1px highlight line.
  • Bitmap or SVG images inside controls (image preview is a separate feature).
  • Italic text; bold remains a heavier face only in the UI font.
  • Continuous animation; only hover/focus transitions redraw.
  • Nested overlays: one popover layer above the panes, no sub-menus.
  • Wrapping or kerned text in cells; each glyph is one cell in editor and terminal.

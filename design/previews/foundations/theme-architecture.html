Theme architecture

A theme is a plain file of variable overrides. Changing the ramp restyles everything; re-mapping a role restyles one class of surface; a per-view token restyles one region. Users stop at whichever depth they need.

Layer 1

Palette

11-step neutral ramp, an accent hue, four semantic hues.

--re-gray-0 … --re-gray-10 --re-accent-hue: 45 --re-accent: oklch(.72 .17 hue) --re-ok / --re-warn / --re-err
Layer 2

Semantic roles

Surfaces, controls, text, borders, selection, focus, radius, fonts, sizes.

--ui-surface: var(--re-gray-3) --ui-control: var(--re-gray-5) --ui-fg: var(--re-gray-9) --ui-radius: 3px --ui-font / --ui-mono / --ui-size
Layer 3

Per view

Toolbar, tabs, tree, editor, terminal, status, scrollbars. Inherit by default.

--tab-marker: var(--ui-accent) --editor-bg: var(--re-gray-2) --terminal-bg: var(--re-gray-1) --status-accent-bg: var(--ui-accent) --tree-row: 22px

Tint only

[theme "sunset"] accent-hue = 25
